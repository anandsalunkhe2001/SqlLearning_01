Git commands : 
1.git --version [gives version of git]
<br>
2.git config --global [sets your configuration globally]
<br>
3.git config --global user.name "Anand Salunkhe" [sets user name as mentioned in globally git]
<br>
4.git config --global user.email "anandsalunkhe2001@gmail.com"
[sets your email address globally which you have linked with your gitHub account]
<br>
5.git clone yourRepositoryLink
[this gets clone of your repo from git server and stored it at your local]
<br>
6.git status [gives status of your local git with respect to server git 1.modified-existing file modified ,2.untracked-new file,3.unmodified-nothing changes happened,4.staged-file added and ready to become commited]
<br>
7.git add fileName [adds your file to your git staging area{you can add multiple files at one by using 8.git add .}]
